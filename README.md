# نمو — وب‌سایت شرکت مشاوره مدیریت کسب و کار

وب‌سایت لوکس و ایستا (فقط فرانت‌اند) برای شرکت مشاوره مدیریت کسب و کار **نِمُو** — ساخته‌شده با HTML/CSS/JS خالص، بدون فریم‌ورک و بدون هیچ درخواست خارجی (CDN، فونت یا تصویر).

## اجرا

```bash
npm install        # نصب وابستگی‌ها (Tailwind v4، GSAP، anime.js، three.js، فونت وزیرمتن)
npm run build      # ساخت نهایی → assets/css/styles.css و assets/js/*.bundle.js
```

سپس کافی است `index.html` را در مرورگر باز کنید (یا از هر وب‌سرور ایستا استفاده کنید).

- حالت توسعه با بازسازی خودکار: `npm run dev`
- کپی فونت‌ها (فقط پس از تغییر نسخه): `npm run copy:fonts`

## نکته‌ها

- تم روشن/تاریک: دکمه در سرآیند؛ انتخاب کاربر در `localStorage` ذخیره می‌شود.
- داده پروژه‌ها در `src/js/projects.js` است؛ ۱۲ پروژه باقی‌مانده را به آرایه `PROJECTS` اضافه کنید.
- شمارنده‌های صفحه اصلی (ساعت مشاوره، کارفرما، مشاور متخصص) placeholder هستند؛ عدد واقعی را در `data-target` قرار دهید.
- همه فایل‌های build خروجی (`assets/`) هم کامیت شده‌اند تا سایت بدون build هم قابل اجرا باشد.

## ساختار

```
index.html … account.html   صفحات (۱۰ صفحه)
src/input.css                توکن‌های طراحی (Tailwind v4)
src/js/                      سورس ماژول‌ها (main، scenes، projects)
assets/                      خروجی build + فونت‌ها + SVG
scripts/                     اسکریپت‌های build و dev
```
